# HDMI 模式确认与采集恢复

适用于 AX630C 后端。桥片固件发布的 CSI 宽高、帧率可能滞后于 HDMI RX 实际输入；STREAMON 成功或 CSI 寄存器非零均不能证明正在采集有效帧。

编码采集停帧时读取独立 RX 尺寸，两次间隔 20 ms 的一致结果可作为新采集候选。候选暂以 60 fps 配置，实际帧率根据 VIN 完成帧的单调时间戳和序号计算。至少 8 个有效完成帧、跨度至少 200 ms，才发布确认后的宽高和帧率；错误标志、短帧或无有效单调时间戳的帧不参与确认。确认仅验证帧完成与尺寸长度，不能检查图像内容是否正确。

确认结果打包成一个原子模式快照，供输入格式查询与信号轮询读取。RX 持续匹配已武装的候选时，不因旧 CSI 元数据持续存在而退回旧采集尺寸。停止采集清除确认结果，防止下次开流沿用旧确认。`HDMI configured/prearmed` 日志表示采集配置，`VIN confirmed` 才表示已收到足够完成帧。

编码采集与仅预览采集共用 DMA 重试退避：250、500、1000、2000、4000 ms，持续失败时保持 4000 ms；8 个有效完成帧后清除退避。不自动改写 `force_*` 或复位桥片电源。

当前边界：RX 候选尺寸恢复发生在编码停帧路径；仅预览路径只包含 DMA 重试退避。正式 CSI 模式完全不可读或为零时，仍由既有无信号逻辑处理。输入低于10或高于240 fps不发布帧率确认。以上不保证物理 CSI 链路可以锁定，也不改变内核 `/proc/lt6911_info` 对固件元数据的报告。
